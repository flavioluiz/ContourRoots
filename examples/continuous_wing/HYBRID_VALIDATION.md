Kernel tolerances: absolute 1e-3, relative 1e-3. Output tolerances:

absolute physical accuracy. Both assemblies use the same strip equations.
Physical reference checks remain in Tutorial 11 and the prior validation record.

table above does not claim that optional full temporal run was qualified.
All nine channels are included in the algebraic/frequency comparisons.
The matrix time API itself is not restricted to this selected pair.

## Independent review checks (Claude Code)

Run after the implementation, with code independent of the new tests:

| Check | Result |
|---|---:|
| 2×2 rational MIMO, different `IODelay` per channel, ZOH, vs MATLAB `lsim` | 1.4e-9 (after the fixes below) |
| `cdyn` wing model vs scalar `wing_transfer`, 9 channels, 3 complex nodes | 2.0e-14 |
| hybrid vs implicit transfer, 1 strip, 400 nodes on Re s = 6 up to 2e4 rad/s | 1.6e-9, no pivot failure |
| same on the imaginary axis, 10–3000 rad/s, air and vacuum (6000 nodes) | no pivot failure |
| half-span piece at its own cantilever frequency (197.97 rad/s, vacuum) | hybrid unavailable (rcond 5e-17); implicit transfer finite |
| exact cancellation of two identical channels, inputs 1e3 | y = 0, summed estimate 3.4e-8, converged |
| superposition: both loads vs sum of single loads (0.4 s, dt 0.005) | 8.9e-16 |

Defects found and fixed in this review:
1. **ZOH with a delayed direct term** (scalar, present since 0.4): the held
   input at t − T took the previous sample when t − T fell one ulp below a
   grid point (2e-2 error for `(s+3)/(s+2)` with `IODelay` 0.5). Fixed by
   index selection; regression test fails on the old code.
2. **Default shared budget** `MaxEvaluations = 1e6` made the 2×2 case above
   fail; each of its channels alone needs more than 1e6 evaluations in the
   scalar API, which has no such limit. Default is now `Inf`.
3. **Channel-cell models** evaluated all channels at every node requested by
   one channel; now only the requested channel (62 s → 0.6 s).

The tests cover sequential vs hierarchical hybrid connection; interface
signs and static compliance; an unavailable element pivot without
regularization; fixed-size structured evaluation; declared batching;
domain, shape and budget failures; optional symbolic/LTI inputs and an
independent MIMO `lsim` oracle; both holds and all three inversion methods
on qualified fixtures; per-channel transport/direct terms; cancellation;
frozen/serialized kernels and reactivation of inputs.

## Reproduce

From the checkout, run `buildtool test docs`. To regenerate the comparison,
run `setup_contourroots`, add `examples/continuous_wing` to the path and
call `run_hybrid_comparison`. It writes numeric data, the tolerance/parameter
record, the comparison table and figure under `output/hybrid_comparison`.
`buildtool examples` includes that study; the manual build includes its figure.

No matrix mode finder, general transfer-pole/transmission-zero solver or
generic network assembler has been implemented in this delivery.
