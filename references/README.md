# References

The bibliography used by the documentation and the manual is in
[references.bib](references.bib). This folder holds metadata only: no
third-party article is redistributed with ContourRoots.

The distributed-parameter examples (`examples/models/distributed_model.m`)
follow the models of:

> Ruth F. Curtain and Kirsten Morris. *Transfer functions of distributed
> parameter systems: A tutorial.* Automatica 45(5):1101–1116, 2009.
> DOI: [10.1016/j.automatica.2009.01.008](https://doi.org/10.1016/j.automatica.2009.01.008)

Sections 1 (heat), 2 (string), 3.3–3.4 (duct) and 4.2 (beam) of that paper
are used. The normalizations and parameters adopted here are documented in
the code and in [tutorial 7](../docs/tutorials/07_distributed_systems.md).
All numbers produced by ContourRoots are independent computations; no figure
of the paper is reproduced.

## Aeroelasticity

[Tutorial 9](../docs/tutorials/09_aeroelasticity.md) uses Perry (2015),
NASA/TP-2015-218765, Appendix C / Table CI as the primary two-DOF flutter
benchmark; Edwards (1977), NASA-CR-148019 for generalized Theodorsen
aerodynamics; and Kaiser and Quero (2022), DOI 10.3390/aerospace9030127,
Eq. (33), Table 1 and Figure 2 as a second dimensional benchmark.
Bibliographic entries are in `references.bib`; the source documents are not
redistributed.
